# Health Monitoring System

A simple Python project for collecting and monitoring village health information. The system records hospital details, water quality, patient information, and displays a health dashboard.

## Features

- Hospital details
- Water quality checking
- Village management
- Patient registration
- Disease tracking
- Dashboard summary

## Technologies

- Python
- Object-Oriented Programming (OOP)

## How to Run

```bash
python HMS.py
```
